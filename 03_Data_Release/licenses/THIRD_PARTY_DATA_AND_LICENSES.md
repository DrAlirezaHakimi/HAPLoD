# Source rights and redistribution gate — HAPLoD v1.1

This document describes checks, **not a grant of rights**. Before releasing the data record, the authors must verify the exact licences and any redistribution restrictions for files and derived tables.

| Upstream source | Identifier | Licence / outstanding evidence |
| --- | --- | --- |
| Stoll (2022) | https://doi.org/10.18710/TVZDBF | DataverseNO record identifies CC0; verify exact file/version and provenance |
| Rojo et al. (2019) | https://doi.org/10.1594/PANGAEA.903058 | PANGAEA record identifies CC BY 4.0; cite and indicate modifications |
| IMPMCT / Fang and Ding (2025) | https://doi.org/10.5281/zenodo.17142448 | Independently verify the *dataset record* licence (article licence is not sufficient) |
| Farjami and Kazemi (2023) | https://doi.org/10.5281/zenodo.8278111 | Verify dataset record terms and co-owner rights |
| ERA5 / ECMWF C3S | https://cds.climate.copernicus.eu/datasets/reanalysis-era5-single-levels | Trace exact products, transformations and required attribution |

A CC BY licence applied to original HAPLoD compilation work cannot override rights held by upstream data creators. If the complete release includes third-party files not cleared for redistribution, obtain explicit permission, exclude/rework those materials and revise counts/claims accordingly, or discuss a compliant review-access approach with ESSD.

The software licence is also subject to confirmation by all relevant code owners. No software reuse licence is implied by this statement.
